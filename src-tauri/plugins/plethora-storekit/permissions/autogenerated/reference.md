## Default Permission

Allows the StoreKit 2 billing plugin's product/purchase/entitlement/restore
commands to be invoked from the frontend.

#### This default permission set includes the following:

- `allow-storekit-get-products`
- `allow-storekit-purchase`
- `allow-storekit-current-entitlements`
- `allow-storekit-restore`
- `allow-storekit-start-transaction-listener`
- `allow-storekit-manage-subscriptions`
- `allow-storekit-app-account-token`
- `allow-storekit-set-app-account-token`
- `allow-register-listener`
- `allow-remove-listener`
