## Default Permission

Allows HealthKit availability checks, explicit read authorization, anchored
sleep/biometric queries, and background delivery toggle.

#### This default permission set includes the following:

- `allow-healthkit-get-availability`
- `allow-healthkit-request-authorization`
- `allow-healthkit-query-sleep-sessions`
- `allow-healthkit-query-physiological-samples`
- `allow-healthkit-query-anchored-changes`
- `allow-healthkit-enable-background-delivery`
- `allow-healthkit-disable-background-delivery`
- `allow-register-listener`
- `allow-remove-listener`
