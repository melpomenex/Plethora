## Default Permission

Allows Health Connect SDK availability checks, explicit runtime permissions,
sleep/physiological queries, and incremental change tracking.

#### This default permission set includes the following:

- `allow-healthconnect-get-sdk-status`
- `allow-healthconnect-get-granted-permissions`
- `allow-healthconnect-request-permissions`
- `allow-healthconnect-read-sleep-sessions`
- `allow-healthconnect-read-physiological-records`
- `allow-healthconnect-get-changes-token`
- `allow-healthconnect-read-changes`
