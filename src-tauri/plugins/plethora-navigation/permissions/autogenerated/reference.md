## Default Permission

Allows the trusted main app window to coordinate Android system Back requests.

#### This default permission set includes the following:

- `allow-attach`
- `allow-claim`
- `allow-acknowledge`
- `allow-detach`
- `allow-register-listener`
- `allow-remove-listener`
