## Default Permission

Optional AppSearch derived index; SQLite remains source of truth

#### This default permission set includes the following:

- `allow-search-status`
- `allow-retrieve`
- `allow-upsert-document`
- `allow-delete-document`
- `allow-rebuild-index`
