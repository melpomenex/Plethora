# Article Import Fixture Corpus

Deterministic regression fixtures for the Web Article Import Pipeline
(`overhaul-web-article-import`, tasks 10.1–10.3). Each case is a directory
with:

- `page.html` — the static page a share would have fetched,
- `expected.json` — assertions about the imported article (title, authors,
  date, site, `minWords`, `mustContain`/`mustNotContain` body text, image and
  caption expectations, `expectedExtractor`, `confidenceAtLeast`,
  `noSiteSpecific`, `renderedFallbackRequired`, or `expectsFailure`),
- `rendered.html` (only `js-rendered-shell`) — the DOM the fake rendered
  capture returns after "hydration".

## Capture policy

Fixtures are **crafted structural replicas**: real site skeletons generalized,
synthetic prose generated by `scripts/generate-article-import-fixtures.mjs`
(rerun it after editing templates). The one exception is the Mother Jones
regression replica, which keeps the real title/author/date —
"The Trumps' Crypto Project Just Got One Step Closer to Becoming a Bank",
Sophie Hurwitz, August 15, 2026 — with a fully synthetic body. **No verbatim
copyrighted page bodies are stored in this repository.**

The Mother Jones chrome strings asserted absent ("Skip to main content",
"Share on Facebook", "Donate", …) live ONLY in `expected.json` — they are
fixture assertions, never scorer special-cases (`noSiteSpecific: true` also
asserts no `motherjones.com` rule exists).

## Hermeticity

The suite runs offline: `fetchArticleSource` is mocked from the fixture
files and the rendered capture is an injected fake. No fixture or test in
this tree performs network access. Real platform capture is validated by
the manual matrix (task 10.5).

## Engine-winner fixtures

`defuddle-wins` and `readability-wins` are calibrated so one engine
reliably outscores the other, and their `expectedExtractor` values are
pinned observations:

- `defuddle-wins` — chunky "most read" teasers inside the article read like
  prose, so Readability keeps them and pays the chrome penalty; Defuddle
  strips them by class.
- `readability-wins` — the final article section lives in the common
  `.article-bottom` wrapper; Defuddle treats it as trailing chrome and loses
  the content (completeness penalty), Readability keeps it.

On well-formed pages the two engines converge (equal scores; Defuddle wins
the documented tie-break) — the corpus pins where they genuinely diverge.
