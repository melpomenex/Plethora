# Final Incrementum notice release (rebrand task 4.1)

The last Incrementum-branded release from the legacy repo
(`github.com/melpomenex/incrementum-tauri`) adds exactly one user-visible
change: a one-time, dismissible in-app notice telling users that Incrementum
is now Plethora, linking to the Plethora downloads, and explaining that
`.incrementum` backups import directly. The updater is **not** switched —
the release notes say so explicitly, and the patch contains no updater,
identifier, or data changes.

This repository (Plethora) cannot push to the legacy repo, so the change is
delivered as a ready-to-apply artifact:

- **`final-incrementum-notice-v2.7.0.patch`** — unified diff against the
  `v2.7.0` tag (the last Incrementum release). Verified with
  `git apply --check` on a clean `v2.7.0` worktree (2026-08-17).

## Applying and shipping (run in a clone of the LEGACY repo)

```bash
git clone git@github.com:melpomenex/incrementum-tauri.git
cd incrementum-tauri
git checkout v2.7.0 && git switch -c final-notice
git am /path/to/final-incrementum-notice-v2.7.0.patch   # or: git apply && commit
npm ci && npm run build:check                           # gate
# bump the version (e.g. 2.7.1) via the usual release flow, tag, push, release
```

The patch touches only `src/main.tsx`: a guarded block appended after the
share-target redirect that (a) checks a localStorage flag, (b) renders a
styled dialog above the app with localized copy for all six supported
locales (en/zh/es/de/fr/ja, `navigator.language` fallback to English), and
(c) links to `https://github.com/melpomenex/Plethora/releases/latest`.
No updater endpoint, identifier, database, or migration logic is included —
by design (proposal §Phase B item 12: the notice release must not silently
switch the old updater).

## Suggested release notes (verbatim)

```markdown
### Notice
- Incrementum is now **Plethora** — same app, new name and home.
- This is the final Incrementum-branded release. It contains no feature
  changes and does **not** modify the updater: no automatic switch happens.
- To keep receiving updates, download Plethora from
  https://github.com/melpomenex/Plethora/releases/latest and import your
  Incrementum backup — `.incrementum` backup files are supported by
  Plethora directly (Settings → Import/Export). Your Incrementum
  installation and data are left untouched.
```

## Why a patch and not a branch

The Plethora worktree's `origin` points at the Plethora repo; pushing a
branch to the legacy repo from here is out of scope and unsafe. The patch
was generated by diffing the augmented `src/main.tsx` against the `v2.7.0`
blob and validated with `git apply --check` in a throwaway worktree of the
tag (no build was run against the old tree; its CI gates it on push).
