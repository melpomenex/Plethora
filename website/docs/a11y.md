# Accessibility — useplethora.com

Target: **WCAG 2.2 AA**. Automated axe runs in CI on `/`, `/pricing`, `/downloads`, `/privacy`, and `/features`. This document is the **manual keyboard script** for the interactive demo and chrome.

## Always (chrome)

1. Load `/`. Press **Tab**. Focus must land on **Skip to content**.
2. Activate the skip link. Focus must move to `#main`.
3. Tab through primary nav without traps. Every control has a visible focus ring.
4. Hit targets for primary CTAs should be at least **44×44 CSS pixels** once B/E land real buttons.
5. Trust pages (`/privacy`, `/security`, `/terms`, `/refunds`) must not rely on mascot motion for meaning.

## Interactive demo (after D)

Skip this section while `#demo` / `[data-home-demo-slot]` has no interactive controls.

1. Enable the demo (`PUBLIC_DEMO_ENABLED` default is on).
2. Using **only the keyboard**, complete `DEMO_PRIMARY_PATH`: library → item → reader → passage → explain → remember-confirm → card → review-prompt → review-reveal → review-rate → schedule → complete.
3. Every stage must expose a named control (button or link). Do not require pointer hover.
4. Invalid `?kind=` / `?stage=` deep links must snap to `library` without a keyboard trap.
5. Under **prefers-reduced-motion: reduce**, the mascot must not use `animation-iteration-count: infinite`. Pause motion when offscreen or `document.hidden`.

## Forced colors / contrast

With Windows High Contrast or `forced-colors: active`, borders on device frames and buttons must remain visible. Information must not live only in screenshots (adjacent text from E/D).

## Captions / flashing

If any video ships, it needs captions. Knowledge Peck must not flash.
