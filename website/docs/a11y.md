# Accessibility — useplethora.com

Target: **WCAG 2.2 AA**. Automated axe runs in CI on `/`, `/demo`, `/pricing`, `/downloads`, `/privacy`, and `/features`. This document is the manual keyboard and screen-reader script for the Reading Desk, simulator, and chrome.

## Always (chrome)

1. Load `/`. Press **Tab**. Focus must land on **Skip to content**.
2. Activate the skip link. Focus must move to `#main`.
3. Tab through primary nav without traps. Every control has a visible focus ring.
4. Hit targets for primary CTAs should be at least **44×44 CSS pixels** once B/E land real buttons.
5. Trust pages (`/privacy`, `/security`, `/terms`, `/refunds`) must not rely on mascot motion for meaning.

## Reading Desk and simulator

1. Enable showcase-v2 and load `/#demo`. Confirm the Reading Desk is a named region with an ordered five-step list: Collect, Read, Understand, Remember, Return. The chapter text must convey the whole story without relying on the captures.
2. Activate **Try the flow** at Remember. Focus must move to the recommended **Add card** hotspot. Complete the guided path using only named hotspot buttons: Open / Read, Select passage, Learn this, Add card, Show Answer, Good, View connections.
3. Arrow keys may cycle only while a hotspot owns focus. Enter and Space activate that focused button. With focus on `#main`, headings, or site navigation, those keys must not change the scene.
4. Switch Desktop/Mobile, Guided/Explore, and Explore destinations. Announce the new product outcome in the polite live region without reading raw image filenames or visitor content.
5. Press Escape or **Exit demo**. Focus must return to **Try the flow** on the homepage or **Resume flow** on `/demo`; focus must not be trapped.
6. Invalid `?scene=` and `?layout=` values must clamp to `library.ready` and `desktop`, then replace the URL with the canonical safe query.
7. With JavaScript disabled or hydration/image loading failed, confirm the Reading Desk heading, five ordered chapters, meaningful first-poster description, and working CTA remain available. An image failure must show a named Retry button.
8. Under **prefers-reduced-motion: reduce**, chapter and simulator outcomes must remain identical with no pulsing or spatial scene transitions. Motion also pauses while the Reading Desk is offscreen.

## Manual screen-reader signoff

Run VoiceOver or NVDA at wide desktop and phone width. Verify the Reading Desk region/heading, list position, scene descriptions, takeover focus, mode/layout pressed states, Explore select label, live outcome after each action, completion message, Exit focus restoration, and JavaScript-free fallback reading order. Record the browser, screen reader, date, and any exceptions with the release evidence.

## Forced colors / contrast

With Windows High Contrast or `forced-colors: active`, borders on device frames and buttons must remain visible. Information must not live only in screenshots (adjacent text from E/D).

## Captions / flashing

If any video ships, it needs captions. Knowledge Peck must not flash.
