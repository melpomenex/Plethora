### Added

- **Dedicated Audiobooks section** — A new top-level Audiobooks tab surfaces a visual bookshelf of every imported audiobook, filterable by status (Not Started, In Progress, Finished, DNF) and sortable by metadata. Playback gains a sleep timer (presets, shake-to-extend, end-of-chapter), a fine-grained 0.5x–3.0x speed slider, volume boost, silence skipping, timestamped bookmarks, and Web Media Session sync for lock-screen / hardware-key control. Multi-part books show cumulative progress with clean track transitions, and a stats strip summarizes daily/weekly listening and completed titles.
- **Ordered, browseable Reading Queue** — Queue items now render in a stable priority order with a visible ordinal position for each entry, and the list scrolls inside the Reading Queue surface so the full queue can be browsed without losing surrounding controls. A long-press on any item opens an action sheet (open/resume, start review, postpone, suspend, dismiss, enter bulk selection), while ordinary tap still opens or starts the item without the long-press triggering it accidentally.
- **Unified feedback orchestration** — A single policy-driven pathway (`src/lib/feedback/`) now connects app events to inline UI, toasts, sounds, haptics, badge, and OS notifications, with per-event channel defaults, quiet-hours, focus suppression, deduplication, and cooldowns honored across Tauri desktop, desktop browser, mobile browser, and installed PWA. The toast container is mounted once at the app root so in-app toasts render again on every surface, the daily review-reminder scheduler is now wired up (in-app toast when focused, OS notification when hidden), and the installed-PWA badge and periodic-sync reminder path are repaired so due-card counts actually drive badges and background reminders.

### Fixed & Improved

- **Focus-timer notifications** — Focus-timer phase completion now routes through the notification service (with quiet-hours and permission recovery) instead of firing raw `new Notification(...)` calls that bypassed the Tauri path.
- **Dead PWA reminder plumbing** — The service-worker `periodicsync` handler previously read a `due-card-count` IndexedDB key that no app code ever wrote, so installed-PWA reminders always saw zero due cards; the key is now written when queue stats load.
- **Call-site feedback consistency** — Review completion (incl. streak milestones), destructive queue/card actions with undo, and document import success/failure now go through the orchestrator instead of each call site reading `localStorage` and deciding channels independently.
