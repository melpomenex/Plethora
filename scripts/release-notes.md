### Added

- **Image-occlusion cards from the browser extension** — Right-click any image on a web page and choose "Create image occlusion card" to draw occlusion regions and save the card directly into your Incrementum collection. A new `/ai/image-occlusion` route renders and persists the card on the Rust side, and the extension hosts an inline editor for drawing regions.
- **Selectable flashcard formats** — AI flashcard generation now lets you choose which card formats to produce (question/answer, cloze, or both). The extension options page exposes the choice and a per-selection card count, and the prompt builder + generator honor the selected types end-to-end.
- **OCR executable picker** — Settings ▸ Documents ▸ OCR now has a Nougat executable field with a file browser. Left blank, Incrementum searches PATH plus common user, Homebrew, pyenv, and Python bin directories, fixing "Nougat not found" on macOS where GUI apps don't inherit the shell PATH. Error messages now point to the setting and show the resolved path.
- **Native AI provider sync** — The active LLM provider from the desktop registry is now pushed to the Rust-side AI service on startup and whenever it changes, so the browser extension's HTTP AI routes see exactly the same provider as the Assistant.
- **Persisted AI preferences** — AI provider/model preferences are loaded from and saved to `ai_config.json` on the Rust side; masked API keys sent back from the settings UI are never allowed to overwrite real keychain secrets.
- **Tab-reactivation recovery for HTML articles** — A new `useTabReactivation` hook detects when a reader tab transitions from inactive back to active and reloads the article iframe, recovering HTML backing stores that WebKit discards while a tab is hidden under display:none.

### Fixed & Improved

- **Card delete no longer reloads the review queue** — Deleting a card from a review session or the learning-cards list now patches the session in place (preserving progress, rating counts, and session id) and removes flicker. The cards list also routes delete through the undoable-operations path.
- **Lazy-loaded images import correctly** — `processHtmlContent` now resolves `data-src` and common lazy-load attributes to absolute URLs, strips unreliable srcset candidates, and forces eager loading, fixing broken images in imported Wikipedia-style and other lazy-loaded articles.
- **Faster, more reliable web imports** — When the browser extension already supplies article text, the import no longer blocks on a second preview-metadata fetch, eliminating a major source of "Failed to fetch"/"Network failed" reports on long articles. The first captured image is used as the import cover when available.
- **Test coverage and extension build hygiene** — Adds a shared, dependency-free helper module for the extension service worker with Node tests, a `test:browser-extension` npm script, plus React and util regression tests for card delete and HTML image import. `.gitignore` now tracks only the extension's source/test files instead of ignoring the whole directory.
