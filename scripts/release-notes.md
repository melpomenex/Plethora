### Fixed & Improved

- **Windows release build restored** — The v1.73.0 Windows installer failed because the sidecar binaries were gitignored (to fix repo bloat / Vercel clone timeouts), leaving the `bin/*.dll` resource glob empty. A 0-byte placeholder is now seeded so the `nsis` bundle builds cleanly.
- **Arch Linux release build restored** — The v1.73.0 Arch package failed with `cmake: command not found` because the Arch job's package list didn't include `cmake`, which is required to build the whisper.cpp sidecar. Added `cmake` to the install step.
- **CI Regression Gate unblocked** — `cargo test`/`cargo check` failed with `resource path 'bin/whisper-...' doesn't exist` after the sidecars were gitignored. `build.rs` now seeds a 0-byte `whisper-<target>` placeholder (extending the existing `sherpa-onnx` pattern) so Tauri's `externalBin` check passes; the runtime already detects empty sidecars and reports a clear "not available" error.
- **OPML import no longer silently fails** — Importing an `.opml` file could appear to do nothing at all: an unhandled rejection in the file-read handler swallowed any error, and the XML parser silently returned zero feeds on malformed input (e.g. a bare `&` in a title). The import handler now wraps every step with clear, translated feedback, and the parser falls back to a tolerant regex pass that recovers every `<outline xmlUrl="...">` entry when strict XML parsing fails.
