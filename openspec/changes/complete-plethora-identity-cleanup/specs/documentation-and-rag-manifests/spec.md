# Specification: Documentation Governance & RAG Clean

## MODIFIED Requirements

### Requirement: Canonical product documentation describes Plethora features directly
The `docs/product/` directory SHALL contain canonical documentation explaining Plethora's features without third-party algorithm provenance or proprietary attribution.

#### Scenario: Adaptive scheduler document teaches Plethora Adaptive
- **GIVEN** `docs/product/features/scheduling/adaptive-scheduler.md`
- **WHEN** the document is rendered or indexed
- **THEN** it describes the 3D Stability Increase matrix, Forgetting Index configuration, and retrievability calculations under feature ID `scheduler.adaptive`, with zero SuperMemo branding or links

#### Scenario: Algorithm Arena document teaches Plethora Precision Arena
- **GIVEN** `docs/product/features/scheduling/precision-arena.md`
- **WHEN** the document is rendered or indexed
- **THEN** it describes shadow evaluation, candidate comparison, and coach advice under feature ID `scheduler.precision.arena`

#### Scenario: Precision Postpone document teaches Plethora Postpone Engine
- **GIVEN** `docs/product/features/scheduling/precision-postpone.md`
- **WHEN** the document is rendered or indexed
- **THEN** it describes priority-weighted backlog redistribution under feature ID `scheduler.precision.postpone`

### Requirement: Help index and RAG search manifests contain zero stale references
The help search index files (`src/features/help/generated/helpIndex.json` and `src/features/help/generated/helpIndexData.ts`) generated by `scripts/build-help-index.mjs` SHALL contain zero occurrences of SuperMemo branding, legacy algorithm codes (`sm18`, `sm20`), or third-party author search aliases.

#### Scenario: Ask Plethora query does not return SuperMemo documentation
- **WHEN** a user searches in Ask Plethora or Command Palette for scheduling information
- **THEN** all returned help chunks, how-to guides, and actions cite Plethora canonical documentation
