# flashcard-studio-sessions Delta Specification

## ADDED Requirements

### Requirement: 20 Rules template available in Flashcard Studio templates
The Flashcard Studio session template repertoire SHALL include the "20 Rules Formulation" template (`id: "twenty-rules"`, shortcut `/20rules`) that populates the session prompt with knowledge formulation instructions following Dr. Piotr Wozniak's 20 Rules.

#### Scenario: 20 Rules template is listed and selectable
- **WHEN** the user views the quick templates in the active session
- **THEN** the "20 Rules Formulation" template is displayed alongside standard templates
- **AND** selecting it populates the active session input with the 20 Rules formulation prompt
