## Current decisions

- `YouTubePlaylistManager.tsx` holds settings draft separately from committed values. Commit on the existing save interaction, show pending/confirmed/error, and retain dirty draft after failure. Read authoritative settings on restart. Preserve the 1–10 playlist input and convert once at import into canonical 0–100 manual priority. Label cadence/queue interval separately from reading revisit. The repository seeds new subscriptions from global defaults (interval 1–50, priority 1–10). Future imports use the effective subscription settings. Changing global defaults preserves existing subscription overrides and imported documents. Protect concurrent duplicate import with existing membership/receipt constraints.
- `commands/video.rs` already exposes `check_youtube_runtime_health`, including version age and JS detection. The command is registered but has no frontend caller in the current source. Connect it to the existing Integrations health display and make diagnostics reflect the actual executable and JS runtime used by `youtube.rs` across metadata, single import, playlist import and transcript extraction. Resolve configured binary and supported runtime through one command builder; emit stable categories for binary missing/unusable, version advisory, JS missing/unusable, unreadable/invalid cookie file, authentication required/denied, unavailable media, transient network and generic failure. Version older than 90 days is advisory. Missing JS is actionable where extraction needs it. Keep original technical diagnostics redacted and scoped.
- Configure cookie file through existing Settings UI with native validated preference persisted in an existing app settings store and hydrated before first import. Keep secret contents out of settings/logs. Validate readable Netscape format and required domain/auth metadata without printing values. Clear stale settings and report invalid paths without assuming account access. Respect valid user authorization and current authentication policy. Offer explicit user-selected browser-cookie source if that workflow is enabled and supported; do not silently broaden credentials. Report which credential mode was attempted without path or profile details. Denial remains denial and retry is explicit after the user changes the environment.
