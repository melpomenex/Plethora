## Why

Plethora stores source-linked highlights but needs a broader annotation interface with reliable import and export.

## What Changes

Extend existing sidecar annotations and render supported native markup and comments. Add selection actions and verified embedded interoperability.

## Capabilities

### New Capabilities

- `pdf-annotation-interoperability` governs original and Reflow overlays, annotation repository, shared context actions, reader sidebar and export service.

### Modified Capabilities

Existing feature deltas remain in their historical changes. This delta defines the additional PDF contract.

## Impact

Original and Reflow overlays, annotation repository, shared context actions, reader sidebar and export service. See the [program dependency graph and verification matrix](../../planning/pdf-first-class-document-platform/README.md).
