## Decisions

- Use `src/utils/reviewUx.ts` as the home for one pure classifier with injected now and time zone. Compare Gregorian date tuples or UTC day ordinals of extracted local calendar parts. Never divide elapsed local hours by 24. Timestamp inputs retain UTC instant semantics. Date-only values are calendar keys without UTC conversion. Invalid timestamps show a neutral unavailable state. First exposure is New when currently eligible and the surface carries no explicit future date. Date details may show an accompanying local due time. Today covers earlier and later timestamps on the current local date; this label alone never changes existing scheduler eligibility. Use shared locale keys with explicit accessibility labels.
- In `src/api/algorithm.ts` and `src-tauri/src/commands/algorithm.rs` add a typed reading-rotation request alongside existing legacy commands. Standard Revisit schedules the validated 1–365 day interval from the explicit action, default 7. Use exact elapsed UTC days for stored offsets and local labels for display. Manual date selection wins. Continue/Next without a scheduling choice records reading progress through the existing writer and preserves dates. Finished exits active rotation through existing lifecycle. Scheduled fields and reading progress stay separate from recall grades and card FSRS. Extracts keep their own rotation/lifecycle, and video extracts keep their independent scheduling. New UI uses explicit reading labels. Legacy IPC callers and historical rating data remain compatible.
- Keep existing immediate availability for new in-queue imports, Q&A/clozes and text/video extracts with queue membership. Respect explicit future dates and creation opt-outs. After a first explicit reading revisit or flashcard rating, the appropriate scheduler owns subsequent dates. Import never simulates recall. No global one-day deferral or retroactive dates.
- Native/browser write only the relevant reading schedule/lifecycle fields, with receipt or revision for retry, and update queue on success. Preserve explicit future due dates, collection scope and historical state. Coordinate exact day semantics with Extract and Reschedule and order invariants with Strict Manual.
