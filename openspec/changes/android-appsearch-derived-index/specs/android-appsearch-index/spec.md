## ADDED Requirements

### Requirement: AppSearch is a derived private index
SQLite remains the source of truth. AppSearch, when enabled, SHALL hold a projection of canonical Plethora ids and SHALL set every schema type as not displayed by the system.

#### Scenario: Delete removes orphans
- **GIVEN** a document indexed in AppSearch
- **WHEN** the canonical document is deleted
- **THEN** all corresponding AppSearch records are removed
- **AND** subsequent search cannot return that id

#### Scenario: Default privacy
- **WHEN** the schema is applied
- **THEN** `setSchemaTypeDisplayedBySystem` is false for every Plethora type
- **AND** private study documents are not eligible for Android system surfaces

#### Scenario: Flag off
- **WHEN** the AppSearch feature flag is off or the plugin is unavailable
- **THEN** `ai_learning` retrieval behaves as today

### Requirement: Embeddings are not generated by AppSearch
Vector fields SHALL be written only from Plethora embedding providers (EmbeddingGemma, Ollama, cloud). If embedding search is unsupported on the device, keyword indexing SHALL still function.

#### Scenario: Hybrid query
- **WHEN** the user searches “that article I read about virtual memory”
- **THEN** retrieval MAY union keyword hits with semantic chunk hits from the existing vector store (and AppSearch vectors if enabled)
- **AND** ranking still returns `RagHit` rows joined to canonical documents
