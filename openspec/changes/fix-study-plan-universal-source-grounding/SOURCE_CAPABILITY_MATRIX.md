# Universal Study Plan Source-Capability Matrix

| Source Type | Storage Location | Readiness / Preparation Gate | Chunking & Indexing Path | Citation Locator (`ExactSearchHitLocation`) | Reader Navigation Support | Privacy & Authority Notes |
|---|---|---|---|---|---|---|
| **PDF** (text layer) | `documents` (`file_type='pdf'`), extracted text | Ready if `content` or per-page text non-empty; `needs-ocr` if scanned/empty | `build_document_chunks` -> `pdf` page-aware `semantic_chunks` | `pdf` (`pageNumber`, `textQuote`, `textOffsetHint`) | Exact page jump + text highlight | Respects `is_ai_excluded`, `is_local_only` |
| **Scanned / OCR PDF** | `documents` (`file_type='pdf'`), `metadata.ocr`, `content` | `needs-ocr` until user-triggered OCR completes; explicit block in source-only if un-OCRed | Indexed once OCR populates text layer | `pdf` (`pageNumber`, `textQuote`) | Exact page / OCR view | User-authorized OCR only (local vs cloud disclosure) |
| **HTML Article / Web Page** | `documents` (`file_type='html'`), `html_content` / `content` | Ready if stripped visible text non-empty | Stripped text chunked in `semantic_chunks` (`html` / heading path) | `html` (`scrollPercent`, `selector`, `textQuote`) | Exact iframe quote scroll/highlight or `%` fallback | Strip HTML tags cleanly without UI-thread DOM stalls |
| **X / Twitter Thread** | `documents` (`file_type='html'`, X metadata) or URL import | Ready when thread text persisted in `content`/`html_content` | Same HTML/thread structured chunking | `html` (`scrollPercent`, `textQuote`) | Opens `XThreadViewer` / HTML view with quote | No live scraping during study generation |
| **Markdown** | `documents` (`file_type='markdown'`), `content` | Ready if `content` non-empty | Heading-aware markdown splitter | `markdown` (`scrollPercent`, `textQuote`) | `MarkdownViewer` quote highlight / `%` scroll | Plain local text |
| **Plain Text (`.txt` / notes doc)** | `documents` (`file_type='other'` or `'markdown'`), `content` | Ready if `content` non-empty | Section/paragraph splitter | `markdown` / `text` (`scrollPercent`, `textQuote`) | `MarkdownViewer` / text view (never `previewNotAvailable`) | Treated cleanly as readable text |
| **EPUB** | `documents` (`file_type='epub'`), EPUB spine / CFI / `content` | Ready if extracted chapters/content present | Chapter/CFI-aware `semantic_chunks` | `epub` (`cfi`, `cfiRange`, `textQuote`, `matchIndex`) | Exact CFI + quote jump in EPUB viewer | Local file or extracted text |
| **YouTube Video** | `documents` (`file_type='youtube'`) + `youtube_transcripts` | Ready if transcript persisted (`content`/`youtube_transcripts`); `needs-transcript` otherwise; explicit action | `chunk_transcript` -> `source_type='transcript'` + `timestampMs` | `youtube` (`timeSeconds`, `segmentId`, `textQuote`) | Opens `YouTubeViewer` at `initialSeekTime` + highlights transcript segment | Never substitutes title/description when transcript missing |
| **Local Video** | `documents` (`file_type='video'`) + `video_transcripts` | `needs-transcript` until user triggers transcription or imports `.srt`/`.vtt` | `chunk_transcript` -> `source_type='transcript'` + `timestampMs` | `video` (`timeSeconds`, `segmentId`, `textQuote`) | Opens `LocalVideoPlayer` at `initialSeekTime` + highlights segment | Respects `is_local_only` for ASR model choice |
| **Audio / Audiobooks** | `documents` (`file_type='audio'`) + `transcripts` / `transcript_segments` | Ready if `transcript_segments` or aligned text/`content` present; `needs-transcript` otherwise | `chunk_transcript` / chapter text with `timestampMs` | `audio` (`timeSeconds`, `segmentId`, `textQuote`) | Opens `AudiobookViewer` at `initialSeekTime` + segment | Checkpoints must NOT alter `content_updated_at` |
| **Podcasts & Episodes** | `podcast_episodes` + `podcast_transcript_segments` (promoted to `documents` w/ `metadata.source='podcast:<id>'`) | `needs-transcript` if un-transcribed; promotion links canonical `documents` row on selection | Syncs `podcast_transcript_segments` -> `semantic_chunks` (`transcript`) | `audio` (`timeSeconds`, `segmentId`, `textQuote`) | Opens `AudiobookViewer` with `episodeId` at exact timestamp | Consent-gated Groq/local ASR; respects `is_local_only` |
| **Lecture / Recording Sessions** | `recording_sessions` + `documents` + `transcript_segments` (`timing_kind`: `measured`/`imported`/`none`) | Ready if segments exist; `coarse` navigation if `timing_kind='none'` | `build_session_chunks` -> `source_type='session'` + `startMs`/`endMs` | `audio` (if timed: `timeSeconds`, `segmentId`, `textQuote`; else quote) | Opens `LearningStudio` at `initialSeekTimeSec` + `initialTranscriptSegmentId` | `is_ai_excluded` and `is_local_only` enforced per `document_id` |
| **Standalone Transcripts** | `transcripts` / `video_transcripts` / `documents` | Ready if segments/text exist | Chunked with segment timestamps if timed | `video`/`audio`/`youtube` or `text` | Opens parent media/document viewer | Same canonical verification |
| **RSS Articles** | `rss_articles` (promoted idempotently to `documents` via `ensureRssArticleDocument`) | Ready if `full_content`/`content`/`summary` non-empty | Promoted `html` doc -> `semantic_chunks` | `html` (`scrollPercent`, `textQuote`) | Opens HTML reader at article + quote highlight | Deduplicated by URL / `rss:<id>` |
| **Extracts** | `extracts` + `video_extracts` (bound to `document_id`) | Ready whenever extract content exists (even on unchunked parent media) | `build_extract_chunks` (`source_type='extract'`) + direct extract verification | Parent doc jump (`pdf`/`epub`/`html`/`youtube`/`video`/`audio`) + `extractId` | Opens document or video extract timestamp | Strict scope check (`extractIds` or parent `documentIds`) |
| **Notes & Annotations** | `annotations` (`content`, `page_number`, `type`) + `extracts.notes` | Ready whenever annotation `content` non-empty | `build_annotation_chunks` (`source_type='annotation'`) + direct DB verify | `pdf` (`pageNumber`, `textQuote`) or parent locator | Opens annotated page / quote | Respects parent document AI exclusion |
| **Image OCR Content** | `documents` (`file_type='image'`), OCR text in `content` | `needs-ocr` until OCR completes; ready once OCR text exists | Indexed as `document` chunk once OCR text populated | `image` (`textQuote`) | Opens `ImageViewer` (plus OCR panel/text if present) | Respects `is_local_only` for OCR engine |
| **Collections & Tags** | `collections`, `documents.collection_id`, `documents.tags` | Expands deterministically into scoped `documentIds` at scope freeze | Uses member document adapters | Inherits member ref locators | Inherits member navigation | Reports AI-excluded/unready count & cap warnings cleanly |
