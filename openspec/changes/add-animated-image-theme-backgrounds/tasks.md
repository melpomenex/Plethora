## 8. Deferred follow-ups

Optimized native video encoding, original GIF playback, additional import formats, portable media packages, multiple quality presets and controls for speed or looping are separate changes. Revisit video only if it materially improves sustained energy or size on qualified targets and addresses alpha, encoder licensing, packaging and fallback. New format adapters must emit the same normalized presentation timeline, poster and validated rendition.
