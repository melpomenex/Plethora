## Current decisions

- Keep `ReviewCardContent.tsx` and `src/utils/cloze.ts` as the parity boundary. Preserve legacy ranges and serialized image/mask metadata. A malformed legacy card shows a repairable state or the existing fallback without crashing/losing source. Front/back and reveal state belong to the item/session, and edit resets reveal only when content changed.
- Classify edit route by supported persisted card kind and payload shape. Q&A and cloze use `InlineCardEditor.tsx`; genuinely structured formats use the existing Studio editor with the same card ID and return context. If historic AI metadata is contradictory, show a repair choice in the editor and preserve old data until save succeeds.
- Use existing learning-item mutation API and persistence path. Merge only changed content/tags, never schedule/source/history fields. Apply confirmed mutation to all subscribed caches and session state, using revision/generation and stable typed IDs. Delayed fetches cannot reintroduce deleted rows. For committed delete use the current advancement/undo primitive, advance once without rating, and preserve session counters. Failed write leaves current row and editable draft. Undo restores original card/history where supported by existing undo contract.
- Deck tags persist through the existing typed tag target mutation and confirmed cache refresh. Show Add on untagged cards; clearing all persists an empty array. Preserve text on failure. Q&A focus effect is mount-only; restore the invoker on close when available.
