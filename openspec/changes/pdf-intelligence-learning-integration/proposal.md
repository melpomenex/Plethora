## Why

Assistant context, OCR, semantic search and learning can disagree about what text exists and where it came from.

## What Changes

Compose grounded PDF context per physical page. Connect canonical and OCR projections to search, TTS, extracts, cards, trails, plans and assessments.

## Capabilities

### New Capabilities

- `pdf-source-grounded-intelligence` governs canonical page projection, OCR providers, Assistant context and citations, semantic index, shared learning artifacts.

### Modified Capabilities

Existing feature deltas remain in their historical changes. This delta defines the additional PDF contract.
