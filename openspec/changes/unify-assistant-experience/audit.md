## Implemented and correctly wired within inspected boundaries

1. `orchestrator.ts:145` gates supplied privacy documents, resolves provider policy, plans video context, assembles prompts, routes grounded versus ordinary turns, and parses tools. `scopes.ts:117` already supports optional source context in Chat and strict Document/Library grounding. Ordinary general discussion must be preserved, not reintroduced as a new capability.
2. `promptBuilder.ts:127` rewrites short/coreferential queries using recent turns; assembly retains budgeted history and lower-trust rolling summaries, protects strict transitions, and wraps source material. `workspaceGrounding.ts:46–74` and `DocumentQATab.tsx:1495` now forward conversation history. Existing history is a heuristic text rewrite, not a durable typed reference graph.
3. `libraryTask.ts` → `retrieveFromLibrary` in `src/api/ai-learning.ts` → registered AI-learning Tauri commands → `ai_learning/retrieval.rs:64`. Rust applies explicit document filters to both semantic and lexical paths; `candidate_docs` at 104 uses the explicit set rather than unioning unrelated FTS candidates. `MAX_K=50`, bounded heap scoring and neighborhood dedup are present. FTS fallback returns `lexicalOnly` when embeddings are unavailable/stale. It is a relevant subset, not proof of exhaustive corpus coverage.
4. `libraryTask.ts` deduplicates/budgets whole chunks, wraps sources as untrusted, calls structured `runTask`, and validates source IDs/quotes with `schemas/libraryAnswer.ts`. `quoteIsGroundedIn` normalizes punctuation/whitespace and supports ordered ellipsis clauses. Validity establishes quote membership, not semantic entailment of every claim.
5. `DocumentQASources.tsx:128–221` fetches full document metadata/content, versions its resolution cache, ignores stale effects, uses `resolveCitationLocation`, and opens via `openDocumentAtLocation`. It already shows honest unavailable states. The resolver handles PDF form-feed page boundaries, EPUB/article/Markdown quote matching and media transcript positions. Existing fallback matching uses 120/60-character prefixes and first occurrence; it cannot prove an ambiguous repeated quote is the exact occurrence.
6. `contextResolver.ts`, `videoContextPlanner.ts`, `videoMapReduce.ts` supply full transcripts when within budget, query/playback/timestamp windows, semantic assistance, and cached hierarchical whole-video synthesis. Indexer reads timed transcripts (`indexer.rs:481`); retrieval exposes timestamp locations. Do not propose a new transcript backend or claim all video answers are grounded merely because a transcript exists.
7. `MobileAssistantHost`, `gesture.ts`, `useAssistantSheetGesture`, `motion.ts`, `viewport.ts` already implement pill-local invocation, handle-local settling, closed/partial/expanded geometry, overlay priority, deliberate threshold/haptic events, fullscreen/review suppression, focus and keyboard restoration. This is the host to keep. Its partial state is currently modal: HEAD sets the entire shell inert and locks reading scroll for any open state. Visible reading is not currently interactive reading.
8. `useComposerDictation.ts` and `lib/speech/dictation.ts` already coordinate capability checks, consent, on-device requirements, insertion at the saved selection, generation/session guards, cancellation on editing/background, and stop-without-submit. `ComposerDictationControl.tsx` has row and compact button forms. Native recognition availability is conditional; keyboard dictation remains ordinary input.
9. `AssistantPanel` already snapshots source/provider state, pins selections and guards late responses with session/epoch identity (`1153–1197,1306`); mobile provenance checks include historical messages. Q&A already defers session changes while processing and preserves a nonce-acknowledged prefill. Replace these with shared guarantees, not claims they do not exist.
10. Existing response/tool actions include card/extract workflows, `/20rules`, message flashcard conversion, persisted artifact links, share/export, section mentions and NotebookLM research drafts. Preserve them through adapters. `AssistantResponseContent.tsx` separates model thinking and supports media timestamp activation; it does not accept canonical structured library citation bindings.
