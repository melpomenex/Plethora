## Why

Plethora's content-driven philosophy is ideal for language learning, but learners need material at a useful lexical challenge around topics they care about. Generation should use their actual lexicon and interests, produce a normal Plethora document with clear provenance, and inherit every language-aware reader feature.

## What Changes

- Add constrained generation for articles, stories, dialogues, summaries, simplified/harder adaptations, and comprehension passages.
- Accept target language/profile, topic/genre, length, coverage/difficulty, new-word count, repeated Learning vocabulary, and grammar/style targets.
- Add “Simplify”/“Make slightly harder” actions on existing documents with generated/adapted provenance and no false source attribution.
- Import generated text as normal documents, optionally generate TTS through existing systems, and allow offline/provider fallback where possible.

## Dependencies

- Hard: profiles, lexicon/knowledge states, processing, lexical coverage/difficulty, existing AI/content-import/document creation.
- Soft: learner-aware tutor, sentence translation, SRS/mining, recommendations.
- Extends AI/content import; does not replace user-selected content or invent source provenance.

## Capabilities

### New Capabilities

- `personalized-language-content-generation`: Lexicon-constrained generation, adaptation, provenance, normal document integration, and provider/privacy behavior.

### Modified Capabilities

- None; generated documents use existing document/reader/import semantics.

## Impact

- AI generation/provider settings, learner-context retrieval, document import/metadata/provenance, coverage/processing queues, TTS, reader/Queue/dashboard, mobile/e-ink UI, and cost/consent tests.
