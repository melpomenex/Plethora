# Live PDF capability audit

Inspected at `190ecc9a`. “Implemented” describes live routes or tests in the checkout. Runtime qualification is tracked separately.

| Capability | Baseline and evidence | Action |
|---|---|---|
| Local open, password, large files | Implemented. `PDFViewer.tsx` wires password callbacks and native ranges. `commands/pdf_mobile.rs` authorizes library paths. `pdfLoadSources.test.ts` covers retry sources. | Preserve non-blocking open. Qualify encrypted and large inputs on devices. |
| Page and continuous layouts, zoom, touch, Vim and resume | Implemented with shortcut and navigation state in `PDFViewer.tsx`, `pdfNavigationStability.ts` and `pdfMobilePreferences.ts`. Navigation tests cover explicit jumps and restoration. | Reuse existing navigation ownership and preference persistence. Verify real device pinch, keyboard and tab switching. |
| Outline, internal/external links and labels | Outline uses `getOutline` and `pdfTocDestination.ts`. PDF.js defaults to forms annotation mode but the wrapper supplies no document link service. Its comment says the layer is off. Printed labels are absent from PDF viewer navigation. | Supply the reader's destination service, constrain external links and add label display without changing locators. |
| Thumbnails, spreads, history, presentation, RTL | Reader surfaces and compact controls exist. Complete PDF-specific thumbnail, spread, history, presentation and RTL behavior remains unqualified. | Extend existing controls, test mixed sizes and keyboard traversal. |
| Rendering lifecycle | `PdfPageView.tsx` caps canvas pixels, cancels drawings and destroys views. `PDFViewer.tsx` virtualizes pages and caches text/geometry. | Measure large documents, tab switches and repeated zoom. Treat PDF text as data in DOM decorators. |
| Native extraction | Unreliable. `processor/pdf.rs` validates one page then extracts every page, filters blanks from bulk text and can synthesize boundaries. `ai_learning/chunker.rs` enumerates the supplied vector. | Read one page or retain a physical slot for each page, remove inferred pagination and refresh derived chunks. |
| Annotations and selections | Partial. `HighlightLayer.tsx`, `pdfTextSelection.ts`, `pdfSelectionPersistence.ts` and canonical anchors support sidecar highlight and selection geometry. Migration 001 defines the general annotations table. `annotationContextMenu.ts` provides shared targets. | Preserve legacy rows, qualify cross-page/rotation/reflow and develop annotation editing and embedded export independently. |
| Canonical reflow | Duplicated. `pdfCanonicalCollector.ts` sends PDF.js data into `src-tauri/src/pdf`. Rust model v2/rust-hybrid-v3 includes words, reading order, roles, tables, figures and source geometry. Original/reflow anchors work through `pdfAnchorResolver.ts`. A JavaScript reflow analyzer/cache also exists. | Lead with canonical pages, treat difficult regions as visual, keep fallback during qualification. |
| Rollout | Inconsistent. `pdfFeatureFlags.ts` has both flags defaulting true while `add-pdf-reflow` D14 still lists open memory and device gates. | Record shipped behavior and explicit overrides. Qualify before eliminating legacy support or expanding defaults. |
| OCR | Partial and duplicated. `PdfOcrManager.tsx`, `pdfCanonicalOcr.ts` and full-document conversion use existing engines through different consumers. `docs/OCR_FEATURES.md` describes provider settings. | Reuse provider routing, persist provenance per page, index verified OCR geometry and qualify review/export. |
| Search and TTS | Implemented for native text and canonical ready pages in `PDFViewer.tsx`. Fixed search and canonical search have different completeness behavior. | Feed a page-scoped projection to both. Keep failed pages and OCR discoverable when available. |
| Assistant | Partial. `utils/assistantContext.ts` and queue/viewer resolvers exist despite unchecked historical spec tasks. In `PDFViewer.tsx`, any ready canonical page suppresses the entire native portion of a window. Previous context may survive an empty window. | Assemble by page, scope to document and current position, report missing evidence, pass real citation locators. |
| Index, Reading Trails, Study Plans | Partial. `ai_learning/indexer.rs` consumes paged text and separately extracts figures. `commands/study_trails.rs` can compact sparse chunk pages. Source locators feed existing study navigation. | Preserve physical IDs, qualify citations after refresh and integrate canonical/OCR projections. |
| Export, forms and import | HTML conversion and password opening exist. `commands/document.rs::import_pdf_highlights_as_extracts` imports selected native annotations as page-linked extracts without geometry or deduplication. General lossless page editing, qualified annotation export and persistent form export lack a verified Plethora workflow. | Start with validated Save As transformations. Qualify forms/signatures and defer any claim of redaction until removal is proven. |
| Packaging and checks | `.github/workflows` contains native build, mobile build and Rust test workflows. Local gates include docs/type/build, Vitest, Cargo, memory driver and anchor-normalized `bench:check`. | Keep native dependency count stable and verify packaging where the device/toolchain is available. |

Related changes remain sources of requirements and fixtures. `add-pdf-reflow` owns its original rollout gates. `fix-pdf-assistant-context-window` and `fix-ocr-html-full-pdf` cover earlier repairs. This program extends their runtime behavior and records evidence independently of historical checkbox state.
