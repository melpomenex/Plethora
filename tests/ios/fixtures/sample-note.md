# Incremental Reading Note

Incremental reading is a learning technique that allows you to read and review dozens or hundreds of articles and books in parallel.

## Key Principles
1. **Prioritization**: Assign priority scores to extracts.
2. **Spaced Repetition**: Re-encounter concepts right before you forget them.
3. **Active Recall**: Convert passive reading into active test items.

This note serves as a native iOS E2E automation fixture.
